# Abdulrahman Expert Portfolio

Public professional portfolio for Abdulrahman Bakor Howsawy.

## Purpose

This repository contains only public-facing professional portfolio content. It is intentionally separated from the private `personal-ai-agent` repository.

## Public site files

- `index.html` — portfolio content and structure
- `styles.css` — visual design
- `links.js` — verified public professional/social links

## Safe update workflow

For all future content or design changes:

1. Create a feature branch.
2. Make the smallest relevant change.
3. Open a Pull Request to `main`.
4. Review factual claims, privacy, links, mobile layout, and clinical wording.
5. Merge only after approval.
6. GitHub Pages deploys automatically from `main`.

## Content rules

- Do not add secrets, API keys, tokens, service-account files, private operational state, or private agent code.
- Do not publish patient-identifiable information.
- Do not invent credentials, dates, outcomes, licenses, awards, roles, or project status.
- Clinical AI projects must be described as decision-support unless independently verified otherwise.
- Keep projects marked `in development` until their production status is verified.
- Prefer cautious clinical wording and test–retest reasoning; avoid guaranteed outcomes or unsupported causal claims.

## Source of truth

Professional facts should come from the latest user-approved CV and verified project evidence. When sources conflict, do not guess; flag the discrepancy for review.
